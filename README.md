## Getting Started

To run any of these projects locally on your machine, follow these steps:

### Prerequisites
Make sure you have **Visual Studio 2022** (or newer) installed with the **.NET Desktop Development** workload enabled.

### Installation & Execution

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Madtch/pemrograman.git](https://github.com/Madtch/pemrograman.git)

2. **Navigate into the repository directory.**

3. **Open a Project:**
   * Go to any target folder (e.g., `P01-Pendahuluan`).
   * Double-click the Solution file (`.sln` or `.slnx`) to launch Visual Studio.

4. **Run the Application:**
   * Press `F5` or click the **Start** button in Visual Studio.
